# Demo scenario — Day 28

## Prerequisites

- Обработанная лекция Day 27 (статус `COMPLETED`, есть чанки в индексе).
- Ollama с `qwen3:4b` и `nomic-embed-text`.

## Steps

1. Запустить backend, открыть лекцию.
2. Нажать «Чат по лекции».
3. Задать прямой вопрос: «Что такое скалярное произведение?».
4. Показать ответ и блок «Источники» с номерами чанков и таймкодами.
5. Задать вопрос, требующий нескольких чанков: «Как векторы применяются в машинном обучении?».
6. Задать вопрос вне лекции: «Какая погода в Москве?» — ожидается ответ
   «информации недостаточно» и отсутствие источников.

## API

```bash
curl "http://localhost:8080/api/lectures/<id>/chat?session=s1"
curl -X POST "http://localhost:8080/api/lectures/<id>/chat?session=s1&question=Что%20такое%20вектор"
curl -X DELETE "http://localhost:8080/api/lectures/<id>/chat?session=s1"
```

## Expected result

- Каждый ответ содержит источники, соответствующие реальным сегментам.
- Ответы с RAG точнее и содержат таймкоды; без RAG — свободный пересказ.

## Local proof

- Все эмбеддинги и генерация идут в Ollama на loopback; внешних API нет.

## Known limitations

- Качество зависит от embedding-модели; при смене модели индекс нужно перестроить.
- История чата ограничена `app.chat.max-history-messages`.
